Can useful AI run on this phone?

This unlisted test downloads public, pinned models and runs ten fixed synthetic messages locally in your browser. It does not accept or send your messages. Model hosting can still see ordinary download metadata, such as your IP address.

Pass conditions

  • Required model files: 150 MB or less.
  • Each fixed message: 3 seconds or less on this phone.
  • Arabic output is not clearly wrong on 3 or more of 5 messages.

Before you start

Use Wi-Fi. Keep this tab open. The full three-model run may download more than 400 MB because one deliberately oversized candidate is included as a control. Cached models may make later runs faster.
